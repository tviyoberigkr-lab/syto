# Syto — агрегатор і просіювач новин

Новини України, світу, технологій та ШІ з відкритого списку редакцій, з позначкою, що підтверджено кількома незалежними джерелами.
**CoLaba Production**

## 1. План створення

| Етап | Що | Стан |
|---|---|---|
| 1 | Методика просіювання, список джерел | зроблено |
| 2 | Конвеєр: збір → очищення → переклад → групування → оцінка | зроблено, перевірено на тестових стрічках |
| 3 | Застосунок (PWA): 4 вкладки + «Про Syto», офлайн | зроблено, перевірено в браузері |
| 4 | Прототип одним файлом із демо-даними | зроблено |
| 5 | Перевірка 35 адрес стрічок на живих сайтах | **не зроблено** — потрібен вихід в інтернет |
| 6 | Запуск на GitHub (акаунт і ключ перекладу — власник) | чекає власника |
| 7 | Перший живий прогін, виправлення стрічок, що не відповіли | після етапу 6 |
| 8 | Обгортка для Google Play (TWA) | окремий етап |

## 2. Методика (механіка роботи)

1. **Відкритий список джерел** — `sources.json`. У кожного тип: незалежне ЗМІ, суспільний мовник, державне ЗМІ, незалежне ЗМІ у вигнанні, фактчекери. Анонімних телеграм-каналів і соцмереж немає взагалі.
2. **Збір** чотири рази на день (до 8:00, 12:00, 16:00, 20:00 за Києвом) зі стрічок RSS/Atom. Беруться лише заголовок, короткий опис, час і посилання — повний текст лишається на сайті редакції.
3. **Очищення**: геть HTML і скрипти, записи без дати, старші за 48 год, із небезпечними посиланнями, дублікати.
4. **Переклад** іноземних заголовків українською через ШІ (за ключем). Кожен заголовок перекладається один раз і кешується. Оригінал завжди видно в картці.
5. **Групування**: повідомлення про одну подію зводяться в одну картку (схожість заголовків ≥ 0,5; вікно 36 год).
6. **Статус**:
   - «Підтверджено» — 2+ незалежні редакції;
   - «Одне джерело»;
   - «Лише державне ЗМІ» — державні видання (зокрема Укрінформ і Сіньхуа) підтвердженням не рахуються;
   - «Крикливий заголовок» — опускається нижче.
7. **Порядок**: підтверджене і свіже — вище.
8. **Фейки**: окрема вкладка зі спростуваннями StopFake, VoxCheck, «По той бік новин».

**Межі методу.** Syto не перевіряє факти саме. Кілька редакцій можуть помилитися разом, якщо переказують одне першоджерело. Групування й переклад автоматичні й іноді помиляються. Про це чесно написано в застосунку на сторінці «Про Syto».

## 3. Запуск (робить власник, ~20 хв)

1. Зареєструйся на github.com (безкоштовно).
2. Створи **публічний** репозиторій, `syto` (малими літерами).
3. Завантаж у нього вміст цієї папки (кнопка *Add file → Upload files*).
   Файл автооновлення додай окремо: *Add file → Create new file*, в назву впиши `.github/workflows/update.yml`, у вміст встав текст із файла `workflow_update.yml` і натисни *Commit*. (У папці на диску цей файл лежить як `workflow_update.yml`, бо Claude не має права писати в `.github` на комп'ютері; в архіві `syto.zip` він уже на своєму місці.)
4. *Settings → Pages → Source:* вибери **GitHub Actions**.
5. *Settings → Actions → General → Workflow permissions:* **Read and write**.
6. Переклад (можна пізніше; без ключа все працює, іноземні заголовки будуть в оригіналі):
   *Settings → Secrets and variables → Actions → New repository secret* — один із двох:
   - `GEMINI_API_KEY` — ключ Google AI Studio;
   - `ANTHROPIC_API_KEY` — ключ Anthropic.
   Модель за потреби задається змінною `TRANSLATE_MODEL`, стеля нових перекладів за запуск — `TRANSLATE_MAX_NEW` (типово 200).
7. *Actions → «Оновлення новин» → Run workflow.* Через 1–2 хв сайт буде за адресою `https://ТВІЙ_ЛОГІН.github.io/syto/`.
8. На телефоні відкрий адресу → меню браузера → **«Додати на головний екран»**.

Далі все оновлюється само чотири рази на день.

## 4. Обслуговування

- Додати/прибрати джерело — правка `sources.json` (`"enabled": false` вимикає).
- Яка стрічка не відповідає — видно в застосунку («Про Syto» → червона крапка) і в журналі запуску в Actions.
- Якщо впало понад 75 % стрічок, сайт не оновлюється і лишається попередня версія.

## 5. Перевірка

- `npm test` — 16 автоматичних тестів конвеєра (формати RSS/Atom/RDF, кодування windows-1251, биті стрічки, статуси, переклад, кеш, запобіжники).
- `python3 tests/ui_check.py` — інтерфейс у браузері на екрані телефона, світла й темна тема, офлайн.
- `npm run prototype` — прототип одним файлом.

**Що тести НЕ покривають:** справжні сайти редакцій, справжні ключі перекладу, запуск у GitHub Actions, встановлення на реальний телефон.

## 6. Структура

```
sources.json            список джерел
pipeline/lib.mjs        очищення, групування, оцінка
pipeline/translate.mjs  переклад із кешем
pipeline/build.mjs      збірка site/data/news.json
site/                   застосунок (PWA)
tools/                  демо-стрічки, збирач прототипу
tests/                  тести
.github/workflows/      автооновлення
```
